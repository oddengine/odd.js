# 只读会话

`odd.IM.UI.createView(im, { kind: 'Conversation', readOnly: true, ... })` 从初始化即隐藏输入器，打开会话时不请求广播发送权限，保留订阅、历史、保存确认和已读。具备该配置的实例不会因为重新打开会话恢复输入；配置为可发时，广播发送授权明确返回 NotAllowedError 会降为只读，其它连接/系统错误正常报告。

只读是呈现与少申请权限的选项，安全边界仍在服务端签发的权限上限和节点执行。不能通过修改客户端配置获得发送权；用户资格变化后应重新取得身份与会话授权。已有可靠会话按 conversationId 查看；尚无可靠会话的联系人不能靠只读客户端创建发送关系。
